# smueval-bot · 南医大随堂评价助手

一个 DeepSeek Harness 插件：每天定时用**真实浏览器点击**的方式，自动完成南方医科大学
「教学服务平台」（`wjiaowu.smu.edu.cn`）的**随堂评价**。

- 默认每天 **20:30 ± 30 分钟**跑一次，一次把**今天 + 昨天**的课都评掉
- 定时点电脑没开时，下次启动会**自动补跑**
- 评分默认 **2 个四星 + 2 个五星**，四星数量与位置随机
- 建议文本从模板池随机抽取，约 **35% 留空**（该题本身是选填）
- Token 自动从**电脑版微信**读取，失效时无需手工复制

---

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows（用到微信和 Chromium 浏览器的本地存储） |
| DeepSeek Harness | 桌面版 |
| 浏览器 | Microsoft Edge 或 Google Chrome（任一即可） |
| 微信 | 电脑版微信（**必须是电脑版**，手机微信不行） |
| 账号 | 南方医科大学在校生，且已在微信端绑定过教学服务平台 |

## 安装

1. 把整个 `smueval-bot` 文件夹放到 DSH 的工作区目录下，例如：

   ```
   <工作区>\smueval-bot\
   ```

2. 在 DSH 里安装这个 bundle（它会自动 `pnpm install` 拉取 `playwright-core`）：

   ```
   plugin_manager install_bundle  <工作区>\smueval-bot
   ```

   安装完成后插件会自动启用，并在「插件」列表里出现三个工具：
   `smueval-bot-runNow`、`smueval-bot-testConnection`、`smueval-bot-getStatus`

## 首次使用：登录一次

装好后**不需要填任何 Token**，但需要让插件能找到你的登录态。任选一种：

**方式 A（推荐，可长期自动续期）**

在**电脑版微信**里打开一次 `https://wjiaowu.smu.edu.cn/` 并正常登录。
之后插件会自己从微信的本地存储里读出 Token，Token 过期后再登录一次即可自动跟上。

**方式 B（临时）**

在你自己的浏览器里登录后，从 `localStorage` 复制 `Token`，填到插件配置的 `token` 字段。

配好之后，先跑一次：

```
smueval-bot-testConnection
```

看到 `Token 有效 ✅ | 学期 ... | 可评 N 条` 就说明通了。

然后可以先试运行一次（只点不提交）：

```
smueval-bot-runNow   dryRun = true
```

## 配置说明

**推荐用可视化配置窗口**：侧栏「插件」→「已安装」→ 点开 `南医大评课助手`，
详情页「描述」下面就是配置区（运行 / 评分 / 登录 / 浏览器 四组），
每项都有中文说明，改完即时生效，不需要编辑文件。
会话输入框下方还有一条状态条显示「每天 20:30」之类的当前设定。

> 面板由插件自己提供，不依赖 DSH 的设置页：
> Host 半侧开一条回环端点 `/api/smueval-bot/config` 读写配置，
> Client 半侧挂到 `plugins.bundle.config`（key = 安装时的包名）。
> 装的包名不是 `@local/smueval-bot` 也能用——客户端会向 Host 问一次真实包名再补注册。

也可以直接改 `cordis.patch.yml`。常改的几个：

| 字段 | 说明 |
|---|---|
| `runTimes` | 运行时间，默认 `["20:30"]`，可写多个 |
| `runJitterMinutes` | 时间随机浮动，默认 30（即 20:00–21:00 之间） |
| `lookbackDays` | 往前补几天，默认 1（今天+昨天） |
| `catchUpOnStart` | 错过定时点后启动补跑，默认开 |
| `fourStarCount` | 四星题数量，默认 2 |
| `varyFourStar` | 四星数量是否随机浮动，默认开 |
| `suggestionEmptyRate` | 建议留空概率，默认 0.35 |
| `dryRun` | 只点不提交，调试用 |
| `headless` | 是否隐藏窗口，默认 `false`（可见更像真人） |
| `mode` | `browser`（默认，真实点击）/ `api`（直接调接口） |
| `showStatusBar` | 是否在聊天输入框下方显示「南医大评课助手 · 每天 20:30」，默认 `true` |
| `systemTask` | 是否注册 Windows 计划任务（DSH 不开也能跑），默认 `false` |

`browserPath`、`profileDir`、`seedProfileFrom` 都可以留空，插件会自动探测。

## 查看状态

```
smueval-bot-getStatus
```

会显示：启用状态、Token 是否失效、运行次数、下次时间、上次结果，
以及 **Token 最后一次有效校验时间 / 失效时间**（用来观察 Token 能撑多久）。

如果显示 `Token：⚠️ 已失效`：

> 去**电脑版微信**里打开一次 `wjiaowu.smu.edu.cn`，下次运行会自动继承新 Token。

**结果回执**：每次跑完（不管是在 DSH 里还是计划任务跑的），聊天输入框下方的状态条会显示
「上次 ✅ 2 门（计划任务）」，配置面板底部也有完整结果。计划任务模式的结果同样会回流到 DSH。

## Token 失效自动续期（微信浮窗）

平台 Token 过期后，插件可以自己去微信里把它换回来。

### 前置条件（一次性设置，必读）

**电脑版微信的浮窗里必须已经有「教学服务平台系统」这一项**，否则插件找不到可点的条目、自动续期会失败。

怎么加（在**手机**上做一次）：

1. 手机微信 → 服务号「南医大教学」→ 底部菜单「**本科**」→ 打开教务系统
2. 点右上角「**···**」→「**浮窗**」（有的版本叫「添加到浮窗」）
3. 电脑版微信点左下角「手机」图标，浮窗面板里就会出现「**教学服务平台系统**」

之后一直有效，不用每次重复。如果在微信里把它从浮窗移除，需要重新加一次。

**没加会怎样**：脚本会返回并显示

```
浮窗里没找到含「教学服务平台」的条目（OCR：...）
```

这句里的 OCR 结果就是当时浮窗面板上真正识别到的文字，可以据此判断是没加、还是被别的条目挤掉了。

**面板**：Token 区 →「用微信浮窗刷新 Token」

**自动**：评课因为 Token 失效失败时，插件会先自动续期一次，成功就直接补跑，失败才退回「监听 10 分钟」。

它做的事（全程不改微信、不注入、不加第三方库）：

```
1. weixin:// 唤醒微信（没开就先启动，并等最多 180 秒让你扫码登录）
2. 点左下角「手机」图标 → 弹出浮窗面板
3. 用 PrintWindow 截图 + Windows 自带 OCR 找到「教学服务平台系统」那一行
   （浮窗顺序会随使用变化，所以必须按文字定位，不能写死坐标）
4. 点它 → 微信内置浏览器打开已登录页面 → OAuth 重跑 → 新 Token 写入本地存储
5. 关掉内置浏览器窗口 → 插件扫描取 Token → 写进配置
```

实测输出（面板会显示）：

```json
{"ok":true,"matched":"教学服务平台系统","clickedX":234,"clickedY":1205,"closed":1}
```

截图留证在 `%LOCALAPPDATA%\smueval-bot\wechat-token-<时分秒>.png`。

**不开 DSH 也能续期**（计划任务模式）：`run-once.mjs` 发现 Token 失效时会自己跑
`tools/wechat-token.ps1`、扫 leveldb、写回配置快照，然后补跑一次。也可以单独执行：

```
node "<插件目录>\tools\run-once.mjs" --refresh-token
```

### 失败会弹窗提醒（不依赖 DSH）

计划任务跑失败时，会弹一个置顶红卡（20 秒后自动消失，点一下也能关）：

```
[x] 南医大评课助手 · 评课失败
    今天 20:30 的评课失败了：Token 已失效，自动续期也没成功。
```

触发场景：评课失败、Token 续期失败、脚本顶层异常。想随时验证弹窗是否正常：

```
node "<插件目录>\tools\run-once.mjs" --test-notify
```

> 注意：这条链路要操作微信窗口，**必须在已登录的桌面会话里跑**（锁屏状态下点不了）。
> 需要微信处于登录态；没开的话脚本会自己启动并等你扫码。

> 为什么必须点一次？微信 PC 端没有"用接口在内置浏览器打开网址"的能力（协议、端口、进程、UIA 全试过）。
> 但浮窗点击走的是微信原生「打开链接」管道，所以 OAuth 会真的重跑——这是唯一有效的入口。

## 期末评课程（手动，整学期一次）

配置面板里有一块 **「期末评课程（手动）」**，只有学期末开放时才用，**平时每天的自动评课完全不包含它**。

| 按钮 | 行为 |
|---|---|
| 评价本学期课程 | 把「评课程」里所有未评价的课逐门打满五星、按常规选项作答并提交 |
| 试运行（不提交） | 走一遍同样的流程，最后不点提交，用来核对分数 |

它的作答策略：

- 12 道星题全部「非常赞同」→ 综合评分 **100**
- 「你担任的职务」→ **无职务**
- 「本学期是否达到课程学习要求」→ **按要求完成了学习**
- 「其他意见或建议」→ 填一句模板；「优秀教师姓名」→ 留空（平台说可不填）
- 第 15 题「自主学习比例」→ 下拉菜单选 **课程学时30%以内**（这个控件是 `van-dropdown-menu`，要点击展开再选，之前误判成"没有控件"）

接口（逆向出来的，供参考）：列表 `POST /appapi/Studentpjwj/course`，表单 `POST /appapi/Studentpjwj/pjCourse`，提交 `POST /appapi/Studentpjwj/saveCoursePj`。

> 它是浏览器点击模式，会真的打开浏览器逐门操作；提交后不可撤销，第一次用建议先点「试运行」看看分数。

## 立即执行（不用等定时）

配置面板最上面有 **「立即执行」** 和 **「试运行（不提交）」** 两个按钮：

| 按钮 | 行为 |
|---|---|
| 立即执行 | 真的评课并提交，和定时那次完全一样 |
| 试运行（不提交） | 走一遍页面、点完所有题，但最后不点提交；用来验证流程和看页面长什么样 |

点下去会**真的打开一个浏览器窗口**（你能看到鼠标自己在动），一般十几秒到一两分钟。
跑完按钮恢复、结果直接显示在按钮旁边；同一时间只允许跑一次（并发会互相抢浏览器 profile）。

不想开面板也行，命令行等价操作：

```
node "<插件目录>\tools\run-once.mjs" --dry-run   # 试运行
```

（注意：命令行版读的是 `%LOCALAPPDATA%\smueval-bot\config.json` 快照，不依赖 DSH 是否打开。）

## 不开 DSH 也能跑（Windows 计划任务）

配置面板 →「界面」→ 打开 **注册 Windows 计划任务**。

打开后插件会：

1. 按「每天运行时间」在系统里建对应任务（`smueval-bot-2030` 这样一条一个时间点）
2. 生成 `%LOCALAPPDATA%\smueval-bot\run.cmd`，内容就是「调用 DSH 自带的 node 跑 tools/run-once.mjs --jitter」
3. **DSH 内的定时器主动让位**，避免同一天被两套定时各跑一遍

计划任务在整点启动，脚本自己再随机等 `runJitterMinutes` 分钟，所以不会每天精确 20:30:00 提交。
只支持 `mode: browser`（API 模式需要另外处理 Token）。

产物都在 `%LOCALAPPDATA%\smueval-bot\`：

| 文件 | 作用 |
|---|---|
| `config.json` | 插件导出的配置快照（CLI 只读，DSH 每次启动刷新） |
| `run.cmd` | 计划任务实际调用的批处理 |
| `run.log` | 计划任务模式的输出日志（排查用） |
| `last-run.json` | 最近一次结果，DSH 打开时读它显示回执 |
| `runs.jsonl` | 历史记录，一行一次 |

想手动试一次（不会提交，只打印配置）：

```
"%LOCALAPPDATA%\smueval-bot\run.cmd" 的 node 行 + --check
```

或者直接：

```
node "<插件目录>\tools\run-once.mjs" --check     # 只读配置并打印
node "<插件目录>\tools\run-once.mjs" --dry-run   # 真的走一遍页面，但不提交
```

取消：把「注册 Windows 计划任务」关掉，插件会删掉自己建的任务。

> 注意：计划任务调用的是 **DSH 自带的 node**（`<DSH_HOME>\dsh-runtimes\...\node.exe`）。
> 如果卸载了 DSH，任务会失效，记得同时关掉这个开关。

## 原理简述

登录态由学校服务端发放 `Token`，存在网页的 `localStorage` 里。插件按这个优先级取：

1. **电脑版微信**的浏览器存储（leveldb）——你在微信里登录过就会更新
2. **本机浏览器**（Edge/Chrome）的 profile——你平时浏览器里登录过就有
3. 配置里的 `token` ——最后兜底

拿到 Token 后，用 Playwright 启动你本机的真实浏览器，真实加载页面、
真实鼠标点击、真实键盘输入，由网页自己发出请求。

## 兼容性 / 发给别人用

整个功能都在这个文件夹里，**没有改动 DSH 本体、也没有改插件市场**。
别人拿到后 `plugin_manager install_bundle <目录>` 就能用，配置存进他自己的 profile。

面板的可选依赖（缺了不会报错，只会降级）：

| 依赖 | 缺了的表现 | 降级后 |
|---|---|---|
| `plugins.bundle.config` 槽位 | 详情页没有配置区 | 只能改 `cordis.patch.yml` |
| `plugins.row.config` | 单行「配置」入口没有 | 用详情页的配置区 |
| `configEditor` 服务 | 表单变只读（会显示要改的 patch 路径） | 手动改 YAML |
| `webServer` 服务 | 面板显示「读不到配置」并提示刷新或改 YAML | 手动改 YAML |

包名不是 `@local/smueval-bot` 也能装：客户端先按常见名注册，再向 Host 问一次真实包名补注册；
Host 找配置条目时按 `id` 找不到会按包名兜底。

## 常见问题

**Q：提示「未找到可用的浏览器」**
装 Edge 或 Chrome，或者在配置里用 `browserPath` 指定浏览器 exe 的完整路径。

**Q：提示「所有 Token 均已失效」**
在**电脑版微信**里打开一次 `wjiaowu.smu.edu.cn`。注意手机微信无效——手机上的数据不会写到这台电脑。

**Q：窗口弹出来又关掉，什么都没评**
看 `getStatus` 的结果。常见原因是当天没有可评课节（课时未结束会显示「时间未到」）。

**Q：想完全自动，不想管 Token**
技术上做不到：学校的登录是微信静默授权，只能在微信客户端内部触发，
外部无法复现；该公众号也没有开放桌面扫码登录。手工点一次的方案已经是成本最低的了。
